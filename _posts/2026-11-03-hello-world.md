This is a sample post to show how the blog pipeline works.

Write your real posts as Markdown files in `_posts/`, named `YYYY-MM-DD-slug.md`, with `title` and `date` in the front matter. GitHub Pages converts the Markdown to HTML automatically, and the posts page sorts them newest-first by date.

Delete this file when you publish your first post.
